## 差价为什么能差几十倍：四笔账

**第一笔是线路，差价的大头。** 同一家服务商、同为 1核1G 的两款机器，走普通国际线路的卖 29 元，走 CN2 GIA（电信精品网）的卖 87 元。差的那 58 元买的是三网回程都走优化线路、晚高峰不卡、延迟稳住。线路看不见摸不着，但一到晚上八点你就知道钱花在哪了。

这笔钱换来的体验可以用数字衡量：洛杉矶到国内，150ms 上下就算优秀线，CN2 GIA 的三网公开实测平均在 166ms 左右（电信约 157ms、联通约 160ms、移动约 182ms），本地基本无丢包。换成日本机房，国内三网平均能压在 60～80ms。物理距离摆在那里，再贵的线路也变不出更短的光缆。

**第二笔是配置。** CPU 核数、内存大小、NVMe 硬盘容量，这三项明码标价，没有玄学。1核1G 和 2核4G 之间的差价是实打实的硬件成本。

**第三笔是带宽和流量。** 300Mbps 和 1Gbps 是两个价，每月 1000GB 和 5000GB 也是两个价。这里有个容易忽略的细节：多数产品默认是共享带宽，明确标注“保证带宽”的才是独享，商家一般承诺 99% 时段达到标称峰值——也就是说，标称 300Mbps 不等于你 24 小时都能跑满 300Mbps。

**第四笔是付款周期。** 月付灵活但单价最高，年付一次掏得多但摊到每月明显便宜，赶上商家的年付折扣码，差价还能再拉大一截。这一笔单独展开说。

## 月付、年付、按小时：三种付法的真实成本

**年付的行业惯例是“付十个月用十二个月”。** 举个能直接算的例子：某家日本机房三档套餐，月付 30 / 45 / 80 元，年付 300 / 450 / 800 元，年付价格正好等于 10 个月月付。折算下来 30 元/月变 25 元/月，45 变 37.5，80 变 66.7。用得久，年付就是白送你两个月。

**按小时计费是第二条路，适合短期任务。** 有的弹性云产品最低 0.049 元/小时起，配置是滑动条式的。要编译个大软件，临时把 CPU 从 1 核拉到 8 核，编译完两小时调回 1 核，只按这两小时的高配置收费。这种场景买月付套餐是亏的——你付了整月的钱，用了两小时。

**折扣码的玩法要看清“循环”两个字。** 循环折扣指的是续费同价，不是首月引流的套路价，这点比一次性优惠码厚道。代价通常也有：用码的订单一般不支持退款，而且月付产品往往不能升级成同等优惠的年付产品。也就是说，打算长期用的人应该一步到位年付 + 折扣码，中途改主意成本很高。

**顺序别搞反：先月付试错，再年付锁价。** 月付多花的钱，本质上是买“验证线路和 IP 到底行不行”的权利。跑一两个月，晚高峰不卡、要访问的平台能正常登录，再转年付。上来就年付，赌的是商家描述和你实际体验完全一致。

## 限制与不适合的人

**“不限流量”不等于“高带宽”。** 不限流量 Lite 的带宽只有 200Mbps，比 100 元进阶版的 500Mbps 还低。厂商用流量不限做卖点，代价通常就藏在带宽栏里。

**纽约机房对大陆不优化，这是官方自己标注的。** 意味着直连体验不会好，官方建议经香港或日本中转、开启 BBR。如果你的使用场景不能加一层中转，这档产品的体验会低于你的预期。

**硬盘给得不大。** 10G 到 120G，跑账号运营、代理环境、轻量应用没问题；要存大量素材、做媒体服务，这个容量很快见底。

**48 小时退款有条件。** 官方页面写的是 48 小时内不满意无条件退款，但按服务条款，大量使用的情况不在其列——带宽超分配 5% 或 20GB（取较小值）、以及存在滥用行为的订单，退款会被拒。想靠退款白用两天高流量，这条路走不通。

**住宅 IP 不保证所有平台通吃。** 不同 IP 段在各平台的表现为有差异，同一个套餐这周能登录的平台，换一段 IP 未必还能。决定长期投入前，先用最短周期验证你要用的那几个平台。

**热门低价档会缺货。** 这在 VPS 行业是常态，低价高配的档位经常显示无货，看到有库存且符合需求，犹豫的窗口不会太长。

## FAQ

**最便宜多少钱能入门？**

如果只求“有台境外机器能跑起来”，18～30 元/月能买到 1核1G 的入门款，年付摊下来还能更低，欧洲一些 OpenVZ 机型甚至能到 3 美元级。但这类机器的线路和 IP 质量都属基础水平。要住宅 IP 这种带属性的资源，门槛会抬到 68 元/月这一档；预算再紧，可以用年付特价版把月均压到 33 元。

**月付还是年付划算？**

算一下就清楚：按行业惯例年付等于 10 个月月付，省两个月，约 17%。但年付锁的是“这一年线路和 IP 都合适”这个判断。头一次用某家，月付多花的钱是验证费；已经跑顺了，年付是纯省钱。顺序是先月付、后年付，别反过来。

**同样配置，为什么价格能差一半？**

三个变量：线路（普通国际线路 vs CN2 GIA，同配置能差 58 元/月）、带宽与流量（300Mbps/3000GB 和 1000Mbps/20000GB 是两个成本）、IP 属性（机房 IP 和双 ISP 住宅原生 IP 的采购成本完全不同）。配置表上那行“1核1G”只描述了四笔账里的一笔。

**便宜的是不是都很卡？**

“卡”通常不是机器性能问题，是线路问题。晚高峰卡成幻灯片，多半是走了拥堵的普通国际线路，而不是 CPU 不够。反过来，一台 29 元的普通线路机器跑脚本、做定时任务完全不卡，因为它压根不需要低延迟。判断标准应该是用途要不要稳定回程，而不是价格高低。

**需要备案吗？**

境外机房不需要。买国内服务器搭博客，光备案流程就能耗掉半个月；境外 VPS 开通即用，今天付款明天上线。这也是日本、香港方向一直有人愿意多付钱的原因之一。

**住宅 IP 和普通机房 IP 差在哪？**

普通机房 IP 集中在少数网段，平台的风控系统早就建好了库，新机器开通时可能已经在名单里。住宅 IP 来自真实 ISP 的宽带线路，在平台看来更接近普通家庭用户。做 TikTok 运营、跨境电商、需要过平台风控验证的场景，这个差别是决定性的；纯粹建站、跑 API，两者没区别，不必为此付溢价。
